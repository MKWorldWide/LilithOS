# Contributing to LilithOS

Thank you for considering contributing to LilithOS! We welcome all contributions, whether they're bug reports, feature requests, documentation improvements, or code contributions.

## 🚀 Getting Started

1. **Fork** the repository on GitHub
2. **Clone** your fork locally
   ```bash
   git clone https://github.com/your-username/LilithOS.git
   cd LilithOS
   ```
3. **Set up** the development environment
   ```bash
   npm ci
   cp .env.example .env
   ```
4. **Create a branch** for your changes
   ```bash
   git checkout -b feature/your-feature-name
   ```

## 🔧 Development Workflow

### Code Style

- Follow the existing code style
- Use TypeScript for all new code
- Write meaningful commit messages following [Conventional Commits](https://www.conventionalcommits.org/)
- Keep PRs focused and limited to a single feature or bug fix

### Testing

- Write tests for new features and bug fixes
- Ensure all tests pass before submitting a PR
- Update documentation as needed

### Pull Requests

1. Make sure your code passes all tests
2. Update the documentation if necessary
3. Submit a pull request to the `main` branch
4. Ensure the PR description clearly describes the problem and solution
5. Reference any related issues

## 🐛 Reporting Bugs

When reporting bugs, please include:

- A clear description of the issue
- Steps to reproduce the problem
- Expected vs. actual behavior
- Any relevant error messages or logs
- Your environment (OS, Node.js version, etc.)

## 💡 Feature Requests

For feature requests, please:

- Describe the feature you'd like to see
- Explain why this would be valuable
- Include any relevant use cases

## 📝 Code Review Process

1. A maintainer will review your PR
2. You may receive feedback or be asked to make changes
3. Once approved, your PR will be merged

## 🏆 Your First Contribution

Looking for your first contribution? Check out issues labeled `good first issue` to get started!

## 📜 Code of Conduct

Please note that this project is governed by our [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.
